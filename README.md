# Finora — Personal Finance Dashboard

A responsive personal-finance dashboard UI built with plain **HTML, CSS and JavaScript** — no frameworks.

## Features

- Overview cards: total balance, income, expenses and savings rate
- Income vs. expenses chart for the last six months
- Quick actions (add income, add expense, transfer)
- Recent transactions list rendered from JavaScript data
- Separate **Transactions** page with shared sidebar navigation

## Run locally

No build step. Clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/alolo9611-create/finora-dashboard.git
cd finora-dashboard
open index.html   # or double-click it
```

## Structure

| File | Purpose |
|------|---------|
| `index.html` | Dashboard page |
| `transactions.html` | Transactions page |
| `styles.css` | Layout, components and design tokens |
| `script.js` | Renders the transaction lists |

All data is fictional sample data.
